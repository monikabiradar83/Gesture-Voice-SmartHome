Gesture and Voice Controlled Smart Home System
Overview

An intelligent home automation system that lets users control appliances using voice commands and hand gestures—no remote or smartphone needed. Designed to be accessible, interactive, and user-friendly.

Features
Offline voice-based appliance control
Gesture-based appliance control
Real-time response system
Safe appliance switching via relay module
Motor control using L298 driver
Technologies Used

Software: Embedded C (Arduino IDE)
Hardware: Arduino Uno, SEN0539 Voice Recognition Module, SEN0285 Gesture Sensor, 1-Channel 5V Relay, L298 Motor Driver

How It Works

User gives a voice command or performs a gesture → Input module detects → Arduino processes → Relay or motor driver activates → Appliance responds.

Applications
Smart homes
Assistive technology for elderly or disabled individuals
Contactless automation
Future Enhancements
IoT integration for remote control
AI-based adaptive voice recognition
Multi-room automation
